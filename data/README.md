# Data

This directory contains the measured input profiles, compact experiment records, seed-level results, and statistical summaries used by AdaInfer.

The complete request-level records are distributed as `AdaInfer_Full_Request-Level_Data_v1.0.0.zip` in the GitHub `v1.0.0` release. Extract that archive into the repository root before regenerating every figure and table.

Key inputs include:

- Jetson Nano latency, memory, and power profiles for Qwen2.5-0.5B/Q4_K_M and Qwen3-0.6B/Q8_0;
- saved LAN round-trip-time observations;
- empirical structured-output and multiple-choice quality records;
- RTX 5060 Ti latency, memory, cold-start, and quality measurements;
- seed-level summaries for stationary, noisy-quality, and non-stationary experiments.
